# Prune 输出可读性改进

## 目标

交互预览原先直接复用了 TSV 输出，导致列错位、长路径换行、待删除项淹没在跳过项中。本次只调整展示，让用户先确认将删除哪些目录，再查看跳过原因。

## 展示与交互

- 保持现有英文 CLI 风格，标题展示基准分支和短 SHA。
- 预览优先展示候选；分支与真实目录分别展示，避免假定两者名称相同。
- 公共目录前缀只显示一次，HOME 下路径使用 `~`，无有效公共前缀时保留各自路径。
- 宽度按实际输出流的终端宽度和 Unicode 显示宽度计算；表格容纳不下时改为分行，长值完整换行，不截断。
- 跳过项默认按原因汇总并排序；`--verbose` / `-v` 展示全部跳过项及完整原因。
- 结果突出成功/跳过/失败数量，失败详情始终展示；全局中止后剩余候选标记为 Not attempted。
- 候选、已删除、跳过、失败分别用青、绿、黄、红区分，无颜色时依然有明确文字标识。
- 交互预览走 stderr，dry-run/结果走 stdout；plain TSV 行与顺序保持原样。

## 契约变更与影响

| 契约 | 变更与兼容性 |
|---|---|
| CLI | 新增 prune --verbose / -v，仅影响人类可读输出。已有参数语义不变，plain 组合下仍输出全部行 |
| 人类输出 | 从全量 TSV 改为候选优先、跳过汇总、宽度自适应；人类标题显示短 SHA |
| 机器输出 | 无变化。四个 TSV 字段、转义、逐项状态、顺序、stderr 完整基准 SHA 和退出码均保持兼容 |
| 内部算法/协议 | 无变化。刷新、基准固定、候选筛选、删除前复核、确认和删除逻辑全部保留 |
| 数据库 | 无变化。DDL：无变化 |
| 持久化数据 | 无变化，无新配置、缓存或迁移；数据兼容影响无变化 |
| 版本 | CLI/core 同步发布 0.2.1，以匹配现有发布流水线。core 算法及 API 无变化 |

## 验证

覆盖候选优先、汇总/verbose、真实分支与路径不一致、Unicode 对齐、窄终端完整换行、特殊字符转义、失败详情、空候选和中止后的未尝试项。集成验证 plain 有无 verbose 输出相同，执行后的结果明确。使用实际 PTY 走查不同宽度和交互确认，真实 Raven 仅执行预览。
